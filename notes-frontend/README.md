# Frontend

Interface de l'application Notes construite avec React, TypeScript et Vite. Elle communique avec l'API backend à `http://localhost:3001/notes`.

## Démarrage

Depuis ce dossier :

```powershell
npm install
npm run dev
```

Ouvrez l'adresse locale indiquée par Vite dans le terminal. Le backend doit aussi être démarré pour que les opérations sur les notes fonctionnent.

## Scripts

- `npm run dev` : démarre le serveur de développement.
- `npm run build` : vérifie les types TypeScript et crée la version de production dans `dist/`.
- `npm run lint` : lance ESLint.
- `npm run preview` : prévisualise la version de production.

Pour les instructions de démarrage de l'application complète, consultez le [README principal](../README.md).
